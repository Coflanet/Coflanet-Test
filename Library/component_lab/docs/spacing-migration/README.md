# Spacing Token Migration

Workspace for the spacing token re-organization project. Each numbered folder owns one phase of the migration.

- `01-audit/` — Inventory of current spacing usage across Figma and code, plus mismatch findings.
- `02-tokens/` — Proposed spacing token scale, naming, and design-system definitions.
- `03-mapping/` — Mapping tables from legacy spacing values to the new tokens.
- `04-apply-log/` — Per-component/per-screen application logs and rollout notes.
